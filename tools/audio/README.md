# Offline audio tools

Nơi đặt Python synth SFX và cấu hình tái tạo khi có task audio cụ thể.
Chưa có generator trong scaffold này. Output dùng trong game import vào
`app/Assets/StarShift/Audio/`; không đưa Python vào runtime Unity.

Workflow thuộc [asset pipeline](../../docs/production/asset-pipeline.md);
feedback và danh mục SFX thuộc [audio/VFX](../../docs/presentation/audio-vfx.md).
